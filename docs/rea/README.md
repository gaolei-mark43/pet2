# PET2 REA 复核记录

本目录记录 PET2 的证据驱动复刻过程。使用 [REA](https://github.com/morluto/rea) 对获授权的 PET 页面进行本地、只读观察；所有结论必须能追溯到对应的页面状态、操作资料或 Mock 实现。

## 边界

- 允许：观察已授权页面的结构、可访问性、静态脚本关系、截图和无值网络结构。
- 不允许：绕过认证、导出 Cookie/令牌、记录密码、调用生产写接口或把原系统数据发布到公开仓库。
- 公开仓库只保存合成 Mock 数据、无敏感值的证据摘要和验收结果。

## 工作流

1. 以独立浏览器配置文件登录获授权系统，并以本机 CDP 端口连接 REA。
2. 对每个目标页采集页面结构、截图与可观察事件；必要时将操作过程按单个场景记录。
3. 将事实登记到 [`evidence-ledger.md`](evidence-ledger.md)，明确来源与置信边界。
4. 以 [`acceptance.md`](acceptance.md) 中的用户动作复验 PET2；失败项先修复行为，再谈视觉细节。
5. 所有公开前变更经过敏感信息扫描，确保不含真实账号、企业邮箱、密码、会话或来源系统标识。

## 当前状态

REA 已安装并注册给 Codex。要进行新的线上采证，需要在隔离浏览器中完成一次获授权登录，然后 REA 才能被动附着到该页面。本目录不会把该浏览器资料、会话或采集到的原始页面数据提交到 Git。

## 已完成的 REA 检查

2026-10-20：对 PET2 的 27 个自有应用文件完成静态 JavaScript 应用图谱分析。REA 以惰性文本方式解析源码，没有执行页面或依赖代码。该检查证明公开副本的模块边界可被审计；它不能证明线上 PET 的运行时行为，也不能替代后续的浏览器页面观察。
