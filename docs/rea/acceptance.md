# 可操作验收清单

以下清单验证的是 PET2 的 Mock 行为闭环，不会触发原系统的任何写操作。

## 流水线

1. 从列表新建或选择一条流水线。
2. 在基础配置、图形编辑、脚本、构建参数之间切换，数据保持一致。
3. 增加、配置、删除阶段或步骤；图形和脚本视图应反映当前模型。
4. 触发一次构建；构建详情应冻结此次阶段、步骤和参数快照。

## 插件

1. 浏览系统插件和自定义插件，并按权限显示可用动作。
2. 创建插件并填写基本信息、来源、编排、执行、输入输出绑定。
3. 在流水线步骤中选择可用插件并保存配置。
4. 运行流水线并查看插件步骤的本地模拟日志和产物结果。

## 用户与角色

1. 新建或编辑角色，选择权限并保存。
2. 将角色关联到合成用户。
3. 切换演示用户后，受限动作不可用且提供原因提示。

验收结果必须写明浏览器、屏幕尺寸、操作步骤和失败原因；截图相似度不能单独视为交互一致性证明。
